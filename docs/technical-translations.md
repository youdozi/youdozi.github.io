# 기술 글의 추가 언어 번역

영어를 기준으로 중국어 간체(zh-CN)·일본어·독일어·프랑스어·러시아어·스페인어를 준비합니다. 기존 영어·한국어 기술 글 36개 주제에 대해 총 216편이 대상입니다. [작업 목록](../.pipeline/technical-translations/queue-055.json)은 현재 영어 원문 경로·해시·한국어 대응 글과 언어별 진행 상태를 고정한 계획 자료입니다. 새 기술 글이나 원문 수정이 생기면 이 목록도 갱신해야 합니다.

첫 묶음은 배열 내적과 부호를 적용한 합계의 12편입니다. 다음 묶음으로 셸 함수·숫자 버전 비교·GitHub 릴리스 조회 3개 주제 × 6개 언어, 18편을 준비했습니다. 수열·숫자 단어·ID 정규화·스택·이름별 빈도·종류 선택 6개 주제의 36편을 한 묶음으로 추가했습니다. 현재 총 11개 주제·66편입니다. 이어서 기존 SEO 핵심 주제를 관련 선행 글과 함께 번역하고, 나머지 학습 경로를 묶어서 진행합니다. 이 우선순위는 기존 편집·SEO 목록을 재사용한 것이며 언어별 검색량을 조사한 결과는 아닙니다. 남은 번역은 25개 주제, 150편입니다.

## 준비한 묶음의 검토

[배열 연산 12편](../.pipeline/technical-translations/batch-050/manifest.json)·[셸 자동화 18편](../.pipeline/technical-translations/batch-052/manifest.json)·[Java 학습 경로 36편](../.pipeline/technical-translations/batch-055/manifest.json)의 고정 목록 및 언어별 Markdown을 확인합니다. [묶음 등록 목록](../.pipeline/technical-translations/batches.json)은 명시적으로 추가한 고정 목록만 검사·게시·격리 미리보기 대상으로 사용합니다. 중복된 묶음 ID나 원고 키는 거부합니다. 본문 전체·제목·설명·표 머리글·그림 설명을 번역했고, 각 원고 옆에 현지화한 그림 편집 원본과 정적 SVG를 두었습니다. Java·셸·JSON 코드와 명령·출력 예제는 원문과 동일합니다. 코드·식별자·참고 링크를 보존하고 각 언어의 숫자 묶음 표기만 현지화했습니다. 아직 없는 번역 주소를 만들지 않으며 관련 글 링크는 현재 실제 존재하는 영어 주소를 유지합니다.

`translate` 스킬에 따라 영어 기준문과 의미를 대조한 뒤 대상 언어만 다시 읽는 AI 자체 검토를 수행했습니다. 별도 AI 세션·원어민·사람의 검토를 했다고 기록하지 않습니다. 원문의 컴파일·실행 확인 문장은 기존 원문 기록의 번역입니다. 이번 번역 작업에서 외부 출처의 현재 사실을 새로 검증했다는 뜻은 아닙니다.

```sh
npm run check:technical-translations
npm run review:technical-translations -- \
  --output ~/.config/youdozi-blog-review/technical-review.html
```

첫 명령은 파일 쓰기 없이 등록된 66편의 원문·원고·그림 해시, 코드 블록과 언어 태그, 인라인 코드, 수치, 문단·제목·표 구조, 참고 주소, 흐름 단계·화살표와 SVG 문구를 확인합니다. 일반 번역 검사와 CI의 Node 테스트에서도 실행됩니다. 이것은 누락·변형 검사이며 부정·조건·용어의 의미를 자동 판정하는 번역 품질 인증이 아닙니다.

특정 묶음만 보려면 `--manifest .pipeline/technical-translations/batch-055/manifest.json`을 함께 지정합니다. 각 묶음의 승인용 해시는 별도로 표시하며 합쳐진 해시로 승인을 확대하지 않습니다.

둘째 명령은 영어와 번역문을 나란히 렌더링한 정적 HTML을 저장소의 모든 worktree 밖 새 파일에만 만듭니다. 원고·그림과 고정 목록의 해시를 확인하며 파일 권한은 600입니다. 그림을 포함해 추가 다운로드 없이 열 수 있고 외부 스크립트·통신은 CSP로 차단합니다. 참고 링크를 직접 누르면 외부 페이지로 이동할 수 있습니다. 덮어쓰기·승인 버튼·게시 기능은 없습니다. 현재 작업 파일을 읽으며 HTML에는 고정 목록 해시를 표시합니다. 커밋 시점의 스냅샷을 만드는 기존 뉴스 번역 검토 도구와는 구분합니다.

## 공개 상태와 남은 구현

66편은 `.pipeline/technical-translations/`에만 저장하며 Astro 콘텐츠 컬렉션·검색·RSS·사이트맵에 추가하지 않습니다. 이는 사이트 미게시 상태를 뜻하며, 공개 GitHub 저장소에서는 원고와 그림 파일을 열람할 수 있습니다. 공개 글은 425편, 공개 뉴스 번역은 36편, 별도 승인 대기 뉴스 번역은 318편입니다. 원고에는 실제 발행·수정·승인 시각을 만들지 않습니다. 이 PR의 병합 자체를 원고 게시 승인으로 취급하지 않습니다.

기존 원본 글 컬렉션은 en/ko를 유지하고, 추가 언어는 별도의 승인된 기술 번역 컬렉션에서 읽도록 구현했습니다. [승인 후 게시 준비와 격리 검사](technical-publication.md)를 따릅니다. 뉴스 게시 명령에 초안을 넘기거나 원본 글 폴더로 복사하지 않습니다. 현재 미게시 기술 원고 66편의 실제 공개에는 정확한 고정 목록에 대한 사용자 게시 승인과 게시 PR의 검사가 남아 있습니다. Java 배열·셸 자동화의 학습 안내와 안내 목록·이전/다음 글 문구도 6개 언어로 준비했습니다. 추가 언어에 실제 게시된 기술 글이 생길 때만 해당 언어의 안내를 생성합니다. 아직 없는 번역이나 영어 글을 이전/다음 글로 대신 연결하지 않습니다. 나머지 분야의 학습 안내는 별도 번역이 필요합니다.

뉴스 318편은 기존 [뉴스 번역 검토 절차](translation-review.md)에서 확인합니다. 기술 글 첫 묶음 준비는 해당 뉴스의 승인 상태나 게시 순서를 바꾸지 않습니다.
