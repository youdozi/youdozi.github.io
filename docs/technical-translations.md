# 기술 글의 추가 언어 번역

영어를 기준으로 중국어 간체(zh-CN)·일본어·독일어·프랑스어·러시아어·스페인어를 준비합니다. 기존 영어·한국어 기술 글 36개 주제에 대해 총 216편이 대상입니다. [작업 목록](../.pipeline/technical-translations/queue-050.json)은 현재 영어 원문 경로·해시·한국어 대응 글과 언어별 진행 상태를 고정한 계획 자료입니다. 새 기술 글이나 원문 수정이 생기면 이 목록도 갱신해야 합니다.

첫 묶음은 배열 내적과 부호를 적용한 합계의 2개 주제 × 6개 언어, 총 12편입니다. 이어서 기존 SEO 핵심 10개 주제를 관련 선행 글과 함께 번역하고, 나머지 학습 경로를 묶어서 진행합니다. 이 우선순위는 기존 편집·SEO 목록을 재사용한 것이며 언어별 검색량을 조사한 결과는 아닙니다. 남은 번역은 34개 주제, 204편입니다.

## 첫 묶음의 검토

[고정 목록](../.pipeline/technical-translations/batch-050/manifest.json)과 같은 폴더의 언어별 Markdown을 확인합니다. 본문 전체·제목·설명·표 머리글·그림 설명을 번역했고, 각 원고 옆에 현지화한 그림 편집 원본과 정적 SVG를 두었습니다. Java 코드는 원문과 동일합니다. 코드·식별자·참고 링크를 보존하고 각 언어의 숫자 묶음 표기만 현지화했습니다. 아직 없는 번역 주소를 만들지 않으며 관련 글 링크는 현재 실제 존재하는 영어 주소를 유지합니다.

`translate` 스킬에 따라 영어 기준문과 의미를 대조한 뒤 대상 언어만 다시 읽는 AI 자체 검토를 수행했습니다. 별도 AI 세션·원어민·사람의 검토를 했다고 기록하지 않습니다. 원문의 Java 컴파일·실행 확인 문장은 기존 원문 기록의 번역입니다. 이번 번역 작업에서 외부 출처의 현재 사실을 새로 검증했다는 뜻은 아닙니다.

```sh
npm run check:technical-translations
npm run review:technical-translations -- \
  --output ~/.config/youdozi-blog-review/technical-review.html
```

첫 명령은 파일 쓰기 없이 12편의 원문·원고·그림 해시, Java 코드, 인라인 코드, 수치, 문단·제목·표 구조, 참고 주소, 흐름 단계·화살표와 SVG 문구를 확인합니다. 일반 번역 검사와 CI의 Node 테스트에서도 실행됩니다. 이것은 누락·변형 검사이며 부정·조건·용어의 의미를 자동 판정하는 번역 품질 인증이 아닙니다.

둘째 명령은 영어와 번역문을 나란히 렌더링한 정적 HTML을 저장소의 모든 worktree 밖 새 파일에만 만듭니다. 원고·그림과 고정 목록의 해시를 확인하며 파일 권한은 600입니다. 그림을 포함해 추가 다운로드 없이 열 수 있고 외부 스크립트·통신은 CSP로 차단합니다. 참고 링크를 직접 누르면 외부 페이지로 이동할 수 있습니다. 덮어쓰기·승인 버튼·게시 기능은 없습니다. 현재 작업 파일을 읽으며 HTML에는 고정 목록 해시를 표시합니다. 커밋 시점의 스냅샷을 만드는 기존 뉴스 번역 검토 도구와는 구분합니다.

## 공개 상태와 남은 구현

12편은 `.pipeline/technical-translations/`에만 저장하며 Astro 콘텐츠 컬렉션·검색·RSS·사이트맵에 추가하지 않습니다. 이는 사이트 미게시 상태를 뜻하며, 공개 GitHub 저장소에서는 원고와 그림 파일을 열람할 수 있습니다. 공개 글은 기존 423편, 공개 뉴스 번역은 36편, 별도 승인 대기 뉴스 번역은 318편입니다. 원고에는 실제 발행·수정·승인 시각을 만들지 않습니다. 이 PR의 병합 자체를 원고 게시 승인으로 취급하지 않습니다.

기존 게시 스키마의 기술 글 언어는 en/ko뿐이고 뉴스 번역 스키마는 보강 뉴스 ID에 연결되어 있습니다. 따라서 이 초안을 뉴스 게시 명령에 넘기거나 `src/content/posts`로 복사하면 안 됩니다. 실제 게시 전에는 기술 글 전용 승인·원문 동기화 검증, 추가 언어의 기술 글 컬렉션과 경로, 현지화한 그림 자산 준비, 검색·RSS·상호 hreflang·사이트맵·학습 경로를 함께 구현하고 격리 빌드로 검증해야 합니다. 그 결과와 정확한 원고 목록을 검토한 뒤 명시적 게시 승인으로 공개합니다.

뉴스 318편은 기존 [뉴스 번역 검토 절차](translation-review.md)에서 확인합니다. 기술 글 첫 묶음 준비는 해당 뉴스의 승인 상태나 게시 순서를 바꾸지 않습니다.
