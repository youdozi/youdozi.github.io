# 기술 글의 추가 언어 번역

영어를 기준으로 중국어 간체(zh-CN)·일본어·독일어·프랑스어·러시아어·스페인어를 준비합니다. 기존 영어·한국어 기술 글 48개 주제에 대해 총 288편이 대상입니다. [작업 목록](../.pipeline/technical-translations/queue-077.json)은 현재 영어 원문 경로·해시·한국어 대응 글과 언어별 진행 상태를 고정한 계획 자료입니다. 새 기술 글이나 원문 수정이 생기면 이 목록도 갱신해야 합니다.

첫 묶음은 배열 내적과 부호를 적용한 합계의 12편입니다. 다음 묶음으로 셸 함수·숫자 버전 비교·GitHub 릴리스 조회 3개 주제 × 6개 언어, 18편을 준비했습니다. 수열·숫자 단어·ID 정규화·스택·이름별 빈도·종류 선택 6개 주제의 36편을 한 묶음으로 추가했습니다. LRU·실패율 정렬과 HTTP·코드 검색·draw.io 5개 주제의 30편도 추가해 Java 문제 풀이 10개 주제와 개발 도구 3개 주제를 모두 준비했습니다. JDK 기능·String Templates 이력·Temurin 메타데이터와 YAML 검증 4개 주제의 24편을 더해 셸 4개 주제와 JDK 3개 주제도 모두 준비했습니다. 현재 총 20개 주제·120편입니다. 이어서 기존 SEO 핵심 주제를 관련 선행 글과 함께 번역하고, 나머지 학습 경로를 묶어서 진행합니다. 이 우선순위는 기존 편집·SEO 목록을 재사용한 것이며 언어별 검색량을 조사한 결과는 아닙니다. 남은 번역은 28개 주제, 168편입니다.

## 준비한 묶음의 검토

[배열 연산 12편](../.pipeline/technical-translations/batch-050/manifest.json)·[셸 자동화 18편](../.pipeline/technical-translations/batch-052/manifest.json)·[Java 학습 경로 36편](../.pipeline/technical-translations/batch-055/manifest.json)·[알고리즘 마무리와 개발 도구 30편](../.pipeline/technical-translations/batch-056/manifest.json)·[JDK와 YAML 24편](../.pipeline/technical-translations/batch-058/manifest.json)의 고정 목록 및 언어별 Markdown을 확인합니다. [묶음 등록 목록](../.pipeline/technical-translations/batches.json)은 명시적으로 추가한 고정 목록만 검사·게시·격리 미리보기 대상으로 사용합니다. 중복된 묶음 ID나 원고 키는 거부합니다. 본문 전체·제목·설명·표 머리글·그림 설명을 번역했고, 각 원고 옆에 현지화한 그림 편집 원본과 정적 SVG를 두었습니다. Java·셸·Python·YAML·XML·JSON 코드와 검색 쿼리·명령·출력 예제는 원문과 동일합니다. 코드·식별자·참고 링크를 보존하고 각 언어의 숫자 묶음과 날짜 표기를 현지화했습니다. 아직 없는 번역 주소를 만들지 않으며 관련 글 링크는 현재 실제 존재하는 영어 주소를 유지합니다.

`translate` 스킬에 따라 영어 기준문과 의미를 대조한 뒤 대상 언어만 다시 읽는 AI 자체 검토를 수행했습니다. 별도 AI 세션·원어민·사람의 검토를 했다고 기록하지 않습니다. 원문의 컴파일·실행 확인 문장은 기존 원문 기록의 번역입니다. 이번 번역 작업에서 외부 출처의 현재 사실을 새로 검증했다는 뜻은 아닙니다.

```sh
npm run check:technical-translations
npm run review:technical-translations -- \
  --output ~/.config/youdozi-blog-review/technical-review.html
```

첫 명령은 파일 쓰기 없이 등록된 120편의 원문·원고·그림 해시, 코드 블록과 언어 태그, 인라인 코드, 수치, 문단·제목·표 구조, 참고 주소, 흐름 단계·화살표와 SVG 문구를 확인합니다. 일반 번역 검사와 CI의 Node 테스트에서도 실행됩니다. 영어·독일어·프랑스어·스페인어·러시아어의 명시적 월 이름 날짜와 중국어·일본어의 연월일 표기는 같은 날짜로 정규화해 숫자를 대조합니다. 연도 없는 월일에 연도를 추정하지 않으며 모호한 슬래시 날짜·유효하지 않은 날짜·버전 표기는 그대로 유지합니다. 이것은 누락·변형 검사이며 부정·조건·용어의 의미를 자동 판정하는 번역 품질 인증이 아닙니다.

특정 묶음만 보려면 `--manifest .pipeline/technical-translations/batch-058/manifest.json`을 함께 지정합니다. 각 묶음의 승인용 해시는 별도로 표시하며 합쳐진 해시로 승인을 확대하지 않습니다.
