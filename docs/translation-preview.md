# 승인 대기 번역의 격리 빌드 검사

`npm run check:translation-preview`는 게시 승인 대기 중인 번역을 임시 저장소 복사본에서만 렌더링합니다. 현재 기본 대상은 스페인어 53편과 다른 5개 언어 265편, 총 318편입니다. 실제 게시 파일 추가·게시 승인·배포·색인 제출을 수행하지 않습니다.

```sh
npm run check:translation-preview
# 특정 고정 목록만 확인할 때
node scripts/translation-preview.mjs --release .pipeline/translations/releases/spanish-full-031.json
```

## 실행 범위

1. 현재 HEAD를 `git archive`로 임시 디렉터리에 복사합니다. 커밋되지 않은 원고·사용자 파일은 복사하지 않습니다. 결과의 `sourceCommit`이 검사한 정확한 커밋입니다. 작업 중인 변경 사항을 검사한 것으로 해석하지 않습니다.
2. 선택한 release ledger의 원고·원문·AI 검토·근거 해시를 다시 검사합니다. 차단된 항목이나 목록 간 중복이 있으면 중단합니다. 이미 공개된 항목은 임시 파일로 다시 만들지 않습니다.
3. 임시 복사본 안에서만 렌더링용 fixture를 만듭니다. 승인 필드가 필요한 기존 콘텐츠 스키마를 통과하기 위해 `AUTOMATED_RENDER_FIXTURE_NOT_HUMAN_APPROVAL`과 현실의 PR을 가리키지 않는 시험용 번호를 사용합니다. 이것은 실제 사용자의 승인 기록이 아닙니다. 발행·수정 시각도 시험용이며 실제 게시 날짜로 기록하지 않습니다. 기존 게시 함수는 호출하지 않습니다.
4. 정적 빌드와 내부 링크·SEO·메타데이터·탐색·공개 본문 차단 검사를 실행합니다. `npm run build`, 게시 명령, 배포 명령, IndexNow는 호출하지 않고 고정된 로컬 검사 목록을 사용합니다.
5. 임시 번역의 제목·주장·후속 사실이 실제 글 본문과 검색 데이터에 있는지 대조합니다. RSS에 포함된 글은 설명도 대조하고, 번역 언어 RSS의 최근 30개 선택·순서를 검사합니다. 해당 원문의 실제 제공 언어들과 한영 대응 글의 상호 `hreflang` 집합도 확인합니다.
6. 성공하거나 실패하면 임시 복사본을 삭제합니다. 실제 `src/content`, `.pipeline/translations`, `dist`의 파일 지문이 실행 전후 같은지 확인합니다. 외부 동시 수정이 감지되면 실패로 알리고, 사용자의 변경을 덮어써 복구하지 않습니다.

설치된 `node_modules`는 임시 복사본에서 링크해 사용합니다. 실행 전에 `npm ci` 등으로 의존성을 설치해야 하며 Git·tar·현재 프로젝트의 Node·Python 실행 환경이 필요합니다. Linux CI와 macOS에서 사용하는 절차입니다. 일반 오류·검사 실패에 대한 정리를 수행하며, 강제 종료나 운영체제 장애까지 임시 파일 삭제를 보장하는 기능은 아닙니다.

## CI와 게시의 관계

일반 사이트 빌드가 끝난 뒤, 기존 `dist` 업로드 전에 격리 검사를 실행합니다. 일반 산출물의 지문이 바뀌지 않아야 하므로 시험용 번역이 Pages 산출물로 대체되지 않습니다. 임시 복사본은 삭제하며 미리보기 HTML·가짜 승인 파일을 CI 산출물로 업로드하지 않습니다.

공개 번역은 실제 승인 후 기존 release 게시 절차로 별도 준비합니다. 검사 통과를 승인으로 취급하지 않습니다. 기존 공개 번역 36편과 대기 원고 318편의 상태는 이 검사로 바뀌지 않습니다.

2026-10-28의 최초 격리 실행은 시험용 번역 354편을 포함한 글 741편·사이트맵 797개를 검사했습니다. 대기 원고 318편의 주장·후속 사실 738개, 언어 연결 53개 주제, 6개 번역 언어의 RSS 정책을 대조했습니다. 일반 사이트는 글 423편·사이트맵 479개를 유지했습니다. 시험용 수치는 실제 게시·색인 수치가 아닙니다.

## 검증의 한계

이 작업은 저장된 원고와 검토 기록을 재사용하는 렌더링·출력 검증입니다. 새 번역, 사람·원어민의 의미 검토, 외부 출처의 현재 사실 재검증이나 실제 검색엔진 색인을 주장하지 않습니다. 일반 사이트의 현재 상태와 시험용 번역을 포함한 수치는 구분합니다.

번역 언어에 번역 외의 독립 원고가 생기면 RSS 정렬용 날짜 대조 규칙도 확장해야 합니다. 현재 검사는 날짜를 추정하지 않고 그런 구성이 나타나면 실패합니다. 게시 전 검사에 새 조건을 추가하면 `translation-preview.mjs`의 고정 검사 목록도 함께 갱신합니다.
