# 사이트 전체 글 탐색

이번 작업 단위는 전체 글 목록, 공통 메뉴, 언어 전환, 빈 목록과 404의 복구, 사이트맵과 IndexNow, 생성 HTML의 탐색 검증을 하나의 독자 흐름으로 묶습니다. 이후에도 작은 태그나 컴포넌트별로 배포 단위를 나누기보다 문제 발견·화면·검색 노출 설정·검증을 함께 마칩니다.

## 공개 페이지와 언어

`src/lib/discovery.ts`가 실제 언어별 글을 기준으로 메뉴·목록의 대체 언어·복구 경로·사이트맵의 목록 페이지를 계산합니다. 예제 글과 내부 `archive-renewal` 태그는 공개 탐색에 포함하지 않습니다. 글이 없는 기존 목록 URL은 계속 `noindex`로 제공하되 공통 메뉴에서 연결하지 않고 같은 언어의 전체 글 목록으로 복구합니다.

`/{lang}/archive/`는 실제 게시된 글을 연도별로 묶습니다. 원고 발행일의 기존 표시 시간대인 Asia/Seoul로 연도를 계산하며, 글의 발행일·수정일을 바꾸지 않습니다. 컬렉션의 수정 시점은 기록된 탐색 구조 수정 시점과 포함된 글의 수정 시점 중 최신 값입니다. 매번 빌드한 시각으로 갱신하지 않습니다. CollectionPage와 ItemList는 실제 화면의 글과 동일한 순서·수량·주소를 사용합니다.

언어 메뉴에서 같은 글이 없으면 대상 언어 홈으로 이동한다고 표시합니다. 실제 번역본이 있으면 그 글로 바로 연결합니다. 이를 번역 품질 검증이나 모든 글의 번역 완료로 해석하지 않습니다. 새 UI 문자열은 `translate` 스킬로 짧은 문구의 의미와 자연스러움을 자체 검토합니다.

## 검증

```sh
npm run check
npm test
npm run test:python
npm run build
python3 -B scripts/check_discovery.py
```

빌드는 기존 링크·앵커, canonical·hreflang·사이트맵, JSON-LD·공유 정보 검사에 더해 다음 조건을 검사합니다.

- 공개 페이지에서 비어 있는 `noindex` 목록으로 보내는 링크가 없어야 합니다. 사이트 검색처럼 유용한 `noindex` 페이지는 빈 목록으로 취급하지 않습니다.
- 각 사이트맵 URL은 해당 언어 홈에서 실제 `<a href>`를 따라 도달할 수 있어야 합니다. 다른 언어 메뉴를 통한 우회나 리디렉션·검색 화면을 지름길로 세지 않습니다.
- 모든 공개 글은 해당 언어 홈에서 최대 두 번의 링크 이동으로 도달할 수 있어야 합니다. 이는 이 프로젝트의 탐색 기준이며 Google의 순위 조건이 아닙니다.
- 한글 파일 경로와 인코딩된 canonical URL을 동일하게 대조합니다. 비ASCII URL을 조용히 검사 대상에서 누락하지 않습니다.

IndexNow는 사이트맵에 있는 실제 자기 canonical 아카이브 루트만 허용합니다. 임의의 하위 경로·미공개 언어·noindex URL을 알림 대상으로 확장하지 않습니다. 기존처럼 검토 PR에서는 제출하지 않고 승인된 배포 후 변경된 공개 내용만 알립니다. 알림 수락·정적 링크 깊이는 실제 크롤링·색인·검색 순위 측정과 다릅니다.

브라우저 검사는 8개 언어의 320px/1280px 아카이브, 빈 글/주제 목록, 실제 대응 글과 홈 대체 이동, 메뉴의 키보드·바깥 클릭, 404 및 JavaScript 비활성화를 포함합니다. 실제 검색 노출 관측은 `docs/search-growth.md`의 별도 절차를 따릅니다.
