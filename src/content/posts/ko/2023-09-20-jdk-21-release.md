JDK 21에서는 가상 스레드, 순차 컬렉션, 레코드 패턴과 switch 패턴 매칭을 Preview 옵션 없이 사용할 수 있습니다. 반면 문자열 템플릿은 당시 Preview였습니다. Java 버전을 올렸다는 이유만으로 모든 새 기능을 같은 안정성 수준으로 취급하면 안 됩니다.

[Java 21 출시 공지](https://inside.java/2023/09/19/the-arrival-of-java-21/)의 날짜는 2023년 9월 19일입니다. 이 글은 그 릴리스에서 확정된 기능을 현재도 재현할 수 있도록 정리한 기록입니다. 현재 최신 JDK나 운영에 적용할 패치 버전을 추천하는 글은 아닙니다.

## JDK 21 시점의 기능 상태

| 기능 | JDK 21에서의 상태 | 사용할 때 확인할 점 |
| --- | --- | --- |
| 가상 스레드 | 정식 | 많은 I/O 대기 작업을 다룰 때 검토하며 CPU 연산의 가속을 보장하지 않음 |
| 순차 컬렉션 | 정식 | 처음·끝 원소와 역순 뷰를 일관된 API로 다룸 |
| 레코드 패턴·switch 패턴 매칭 | 정식 | 패턴으로 값을 분해하고 분기할 수 있음 |
| 문자열 템플릿 | Preview | 이후 버전에서 유지된다고 가정하면 안 됨 |
| 구조적 동시성 | Preview | 가상 스레드의 정식화와 별도로 판단 |
| Vector API | Sixth Incubator | 정식 API나 Preview와 구분 |

전체 기능을 나열한 표가 아닙니다. Preview·Incubator 상태는 [JDK 21 릴리스 노트](https://www.oracle.com/java/technologies/javase/21all-relnotes.html)에서도 확인할 수 있습니다. 언어 기능의 상태는 [Java 21 언어 변경 문서](https://docs.oracle.com/en/java/javase/21/language/java-language-changes.html)를 기준으로 확인하세요. 문자열 템플릿은 JDK 23에 포함되지 않았으므로 [해당 기능의 이력과 표준 대안](/ko/posts/2023-09-23-jdk-21-string-templates/)을 따로 참고할 수 있습니다.

## Preview 없이 컴파일하는 예제

다음 코드는 로컬 Zulu JDK 21.0.1에서 실행했습니다. 이 오래된 패치 버전은 재현 환경의 기록이며 운영 권장 버전이 아닙니다. JDK 21의 `javac`와 `java`가 같은 설치 경로를 가리키는지 먼저 확인하세요.

### `Jdk21Example.java`

```java
import java.util.ArrayList;
import java.util.List;

public class Jdk21Example {
    record Point(int x, int y) {}

    static String describe(Object value) {
        return switch (value) {
            case null -> "missing";
            case Point(int x, int y) -> "point=" + x + "," + y;
            default -> "other";
        };
    }

    public static void main(String[] args) throws InterruptedException {
        var names = new ArrayList<>(List.of("alpha", "beta", "gamma"));
        var reverse = names.reversed();
        names.set(0, "ALPHA");
        System.out.println(names.getFirst() + "/" + names.getLast());
        System.out.println(reverse);
        System.out.println(describe(new Point(2, 3)));
        System.out.println(describe(null));
        Thread worker = Thread.ofVirtual().start(() ->
                System.out.println("virtual=" + Thread.currentThread().isVirtual()));
        worker.join();
    }
}
```

```sh
javac --release 21 Jdk21Example.java
java Jdk21Example
```

```text
ALPHA/gamma
[gamma, beta, ALPHA]
point=2,3
missing
virtual=true
```

`reversed()`는 독립 복사본이 아니라 역순 뷰입니다. 원본의 첫 값을 바꾼 뒤 역순 출력의 마지막 값도 `ALPHA`가 됩니다. 빈 컬렉션에서 `getFirst()`를 호출하면 예외가 발생하므로, 예제는 원소가 있는 리스트를 사용합니다. [SequencedCollection API](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/util/SequencedCollection.html)에 뷰의 계약이 설명돼 있습니다.

`Point(int x, int y)`는 레코드 패턴이며 `case null`은 null 입력을 별도로 처리합니다. 가상 스레드는 마지막 줄을 출력하고, `join()`은 그 작업이 끝나기를 기다립니다. 이 예제는 API 동작만 확인하며 처리량이나 지연 시간을 측정하지 않습니다. [가상 스레드 안내](https://docs.oracle.com/en/java/javase/21/core/virtual-threads.html)는 주로 I/O 대기 작업의 동시성에 적합하다고 설명합니다.

실제 전환에서는 사용하는 프레임워크·빌드 도구·관측 에이전트의 JDK 21 호환성을 따로 확인해야 합니다. JDK의 기능 상태와 배포판의 지원 기간은 서로 다른 판단입니다. [Temurin 21 배포 기록과 바이너리 선택](/ko/posts/2023-10-10-temurin-jdk21-delay/)에서는 공급자의 실제 배포 여부를 확인하는 방법을 다룹니다.
