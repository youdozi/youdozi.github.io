### 1. Code scanning shows AI security detections on pull requests

- 출처: GitHub Changelog
- 발행일: 2026-07-15 04:12 (KST)
- 링크: [https://github.blog/changelog/2026-07-14-code-scanning-shows-ai-security-detections-on-pull-requests](https://github.blog/changelog/2026-07-14-code-scanning-shows-ai-security-detections-on-pull-requests)
- 정정 요약: 미리보기 출시 당시 GitHub은 PR의 AI 탐지가 CodeQL 밖의 언어·프레임워크로 검사 범위를 넓힌다고 설명했다. 별도 AI 엔진이 분석하지만 기업 정책 허용·조직 활성화·저장소 CodeQL 기본 분석이 필요했다. 미리보기 발견 사항은 정보 제공용으로 병합을 막지 않았다. 공지는 공개 미리보기 중 Copilot 라이선스와 조직 AI 크레딧을 요구했으므로 자동 승인 관문이나 조건 없는 무료 서비스로 해석하면 안 된다.
- 리뉴얼 검토일: 2026-10-25
- 보강 원고: [한국어](/ko/digest/2026-07-15-ai-code-scanning-preview-and-general-availability/) · [English](/en/digest/2026-07-15-ai-code-scanning-preview-and-general-availability/)

**검토 시점 후속 확인**

- GitHub의 2026-10-15 공지는 AI Scan 정식 제공을 알린다. Copilot 라이선스는 필요하지 않지만 조직의 비공개·내부 저장소에는 GitHub Code Security 또는 Advanced Security가 필요하다고 설명한다. 미리보기 공지와 조건이 다르다.
- 후속 공지에서도 발견 사항은 권고용이며 AI Scan이 규칙 집합을 통해 병합을 막지 못한다고 설명한다. 포크 PR과 Dependabot이 만든 PR에서는 실행되지 않는다.
- 후속 과금 모델은 Code Security AI Credits를 사용하며 기업 AI 사용량의 Advanced Security 제품으로 표시한다. Copilot 라이선스가 필요 없다는 설명을 사용량 요금도 없다는 뜻으로 해석하면 안 된다.

**검토 초점 · 직접 적용 결과가 아닌 편집 제안**

현재 이용 자격·과금 해석에는 후속 공지를 사용하고 미리보기 조건은 과거 정보로 보존할 것을 제안합니다. 권고성 발견에는 사람의 대응이 필요하며 필수 검사나 종합 보안 검증을 대체하지 않습니다.

> AI security detections must be allowed by your Enterprise policy and enabled at the organization level.

>
