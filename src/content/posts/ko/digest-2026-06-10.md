### 3. Security validation for third-party coding agents

- 출처: GitHub Changelog
- 발행일: 2026-06-09 16:12 (KST)
- 링크: [https://github.blog/changelog/2026-06-09-security-validation-for-third-party-coding-agents](https://github.blog/changelog/2026-06-09-security-validation-for-third-party-coding-agents)
- 정정 요약: GitHub은 저장소에서 작업하는 지원 대상 외부 코딩 에이전트에 대한 보안 검증을 정식 제공한다고 공지했다. CodeQL 분석, GitHub Advisory Database를 이용한 신규 의존성 검사, 비밀정보 검사를 설명한다. 검증은 기본 활성화되며 저장소의 Copilot 검증 도구 설정을 따르고 GitHub Advanced Security 라이선스를 요구하지 않는다. 문제가 발견되면 에이전트가 PR을 마무리하기 전에 해결을 시도하지만 성공을 보장하는 의미는 아니다.
- 리뉴얼 검토일: 2026-10-25
- 보강 원고: [한국어](/ko/digest/2026-06-10-third-party-coding-agent-security-validation/) · [English](/en/digest/2026-06-10-third-party-coding-agent-security-validation/)

**검토 초점 · 직접 적용 결과가 아닌 편집 제안**

지원되는 에이전트 연동과 실제 저장소 설정을 확인하고, 보안상 민감한 변경에는 사람의 검토와 별도 검사를 유지할 것을 제안합니다. 탐지율이나 수정 성공률 벤치마크를 재현하지 않았습니다.
