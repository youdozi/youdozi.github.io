### 1. Upcoming cloud data retention policy for closed security alerts

- 출처: GitHub Changelog
- 발행일: 2026-06-30 22:24 (KST)
- 링크: [https://github.blog/changelog/2026-06-30-cloud-data-retention-policy-for-closed-security-alerts](https://github.blog/changelog/2026-06-30-cloud-data-retention-policy-for-closed-security-alerts)
- 정정 요약: GitHub 공지는 2026-09-25부터 github.com·Enterprise Cloud의 종료된 Dependabot 보안 경고에 보존 정책을 적용할 예정이라고 설명했다. Enterprise Server는 명시적으로 제외되며 공지만으로 적용 완료를 확인한 것은 아니다. 공개된 정책에서 열린 경고는 경과 기간과 관계없이 접근 가능하지만 종료된 경고는 종료 후 2년 동안 UI·API에 남는다. 더 오래된 종료 경고는 API 결과에 계속 남는 대신 권한 있는 관리자·보안 담당자가 내려받는 CSV 아카이브로 이동한다.
- 리뉴얼 검토일: 2026-10-25
- 보강 원고: [한국어](/ko/digest/2026-07-01-dependabot-alert-retention-and-archives/) · [English](/en/digest/2026-07-01-dependabot-alert-retention-and-archives/)

**검토 초점 · 직접 적용 결과가 아닌 편집 제안**

오래된 종료 경고에 의존하는 질의·감사 자료 내보내기를 점검할 것을 제안합니다. 해당 계정에서 실제 아카이브 접근과 적용 상태를 확인해야 하며 모든 경고 유형으로 확대하거나 계정·저장소 삭제 후에도 영구 보존된다고 추론하면 안 됩니다.

> Starting September 25, 2026, GitHub will introduce a data retention policy for closed Dependabot security alerts.
>
> [인용 출처](https://github.blog/changelog/2026-06-30-cloud-data-retention-policy-for-closed-security-alerts)

> It does not apply to GitHub Enterprise Server \(GHES\).
>
> [인용 출처](https://github.blog/changelog/2026-06-30-cloud-data-retention-policy-for-closed-security-alerts)

> Open alerts stay fully accessible in the UI and API, regardless of age.
>
> [인용 출처](https://github.blog/changelog/2026-06-30-cloud-data-retention-policy-for-closed-security-alerts)

> Closed alerts stay fully accessible in the UI and API for two years after they are closed.
>
> [인용 출처](https://github.blog/changelog/2026-06-30-cloud-data-retention-policy-for-closed-security-alerts)

> Enterprise, organization, and repository administrators and security managers can download them as a CSV
>
> [인용 출처](https://github.blog/changelog/2026-06-30-cloud-data-retention-policy-for-closed-security-alerts)

### 2. Microsoft Brings AI-Powered Vulnerability Remediation to Azure DevOps with Copilot Autofix

- 출처: InfoQ
- 발행일: 2026-06-30 21:00 (KST)
- 링크: [https://www.infoq.com/news/2026/06/azuredevops-copilot-autofix/](https://www.infoq.com/news/2026/06/azuredevops-copilot-autofix/)
- 정정 요약: Microsoft의 출시 글은 Azure DevOps용 GitHub Advanced Security의 Copilot Autofix를 순차적으로 참여를 허용하는 제한된 비공개 미리보기로 설명한다. 출시 글과 후속 문서를 변하지 않은 제공 상태로 합쳐 서술하면 안 된다. 출시 글의 작업 흐름은 지원되는 CodeQL 경고에서 수정 제안을 만들고 PR을 연다. 기존 검토·빌드 검사는 계속 실행되며 병합 후 다음 CodeQL 스캔이 완료되어야 경고가 해소된다.
- 리뉴얼 검토일: 2026-10-25
- 보강 원고: [한국어](/ko/digest/2026-07-01-azure-devops-autofix-preview-and-billing/) · [English](/en/digest/2026-07-01-azure-devops-autofix-preview-and-billing/)

**검토 시점 후속 확인**

- 검토 시점의 공식 지침은 기능을 제한된 공개 미리보기로 표시하고 추가 사용자를 받지 않는다고 설명한다. 후속 문서의 상태이며 최초 비공개 미리보기 표현이 거짓이었다는 근거는 아니다.
- 현재 지침은 수정 생성이 연결된 Azure 구독에서 과금되는 AI 크레딧을 사용하고, GitHub Copilot 예산·사용자 제한이 해당 Azure DevOps 과금에 적용되지 않는다고 설명한다. 라이선스에 포함된다는 설명을 무료 수정 생성으로 해석하면 안 된다.

**검토 초점 · 직접 적용 결과가 아닌 편집 제안**

참여 승인·지원 경고 유형·연결된 Azure 구독을 확인한 후 수정 생성을 활성화할 것을 제안합니다. 수정은 직접 검토하고 테스트해야 하며 제안 생성만으로 경고가 해결되지는 않습니다.

> Copilot Autofix is available today in limited private preview for GitHub Advanced Security for Azure DevOps.
>
> [인용 출처](https://devblogs.microsoft.com/devops/copilot-autofix-for-github-advanced-security-for-azure-devops/)

> Enablement is processed in waves
>
> [인용 출처](https://devblogs.microsoft.com/devops/copilot-autofix-for-github-advanced-security-for-azure-devops/)

> Your usual review and build gates run on the pull request. Once it merges and the next CodeQL scan completes, the alert resolves on its own.
>
> [인용 출처](https://devblogs.microsoft.com/devops/copilot-autofix-for-github-advanced-security-for-azure-devops/)

> This feature is in limited public preview. Microsoft isn't currently accepting additional users for the preview.
>
> [인용 출처](https://learn.microsoft.com/en-us/azure/devops/repos/security/github-advanced-security-code-scanning-autofix?view=azure-devops)

> Generating a fix consumes AI credits from your organization's Azure billing meter.
>
> [인용 출처](https://learn.microsoft.com/en-us/azure/devops/repos/security/github-advanced-security-code-scanning-autofix?view=azure-devops)

> GitHub Copilot budget settings and user limits configured on GitHub don't apply to Copilot Autofix meter spend in Azure DevOps.
>
> [인용 출처](https://learn.microsoft.com/en-us/azure/devops/repos/security/github-advanced-security-code-scanning-autofix?view=azure-devops)
