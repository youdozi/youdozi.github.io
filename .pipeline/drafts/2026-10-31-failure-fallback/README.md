# 장애 시 fallback 원고

한국어 원고는 `article.ko.md`, 그림 편집 원본은 `diagram.json`입니다. 공개 콘텐츠 경로 밖에 보관한 미게시 원고이며 게시 시각·게시 승인 상태를 부여하지 않았습니다. 이 작업은 한국어 글 작성 범위입니다.

이후 사용자의 명시적 게시 요청에 따라 공개 원고를 `src/content/posts/ko/2026-10-31-failure-fallback.md`에 준비했습니다. 최초 원고와 자체 검토 기록은 당시 상태를 보존하며, 게시 대상은 `publication.json`에 기록합니다. 검사는 공개 본문이 최초 원고와 같은지, 공개 SVG가 그림 원본의 생성 결과와 같은지도 확인합니다.

저장소 루트에서 `python3 -B .pipeline/drafts/2026-10-31-failure-fallback/check.py`를 실행합니다. JDK 21 이상의 `javac`와 `java`가 필요합니다. 원고의 Java 블록을 임시 디렉터리에 추출해 컴파일·실행하고 `execution.txt`와 대조한 뒤 기존 SVG 생성기로 그림을 다시 만듭니다. 외부 통신·추가 Java 의존성은 없습니다.

검사는 정책 분기와 단일 JVM의 허가 반환 의미를 확인합니다. HTTP 타임아웃, 동시 부하, 서킷 브레이커, 분산 캐시, 결제 구현과 운영 복구는 검증 대상이 아닙니다. `review.json`은 자체 검토와 실제 실행·브라우저 확인 범위를 기록하며 공개 본문에 포함하지 않습니다.
