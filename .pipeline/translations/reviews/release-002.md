## 언어 검토

전역 `translate` 스킬로 작성 대화와 이전 판정을 받지 않은 별도 AI 세션에서 대상 언어를 먼저 읽고, 영어 제목·주장·후속 확인·검토 초점과 대조했습니다. 의미상 필수 수정 사항은 발견하지 못했습니다. CodeQL 프랑스어 제목은 자연스럽게 다듬고 해당 제목을 재확인했습니다. 독일어 날짜 표기 제안은 선택 사항으로, 원문과 프로젝트 날짜 대조 규약을 유지하기 위해 ISO 표기를 보존했습니다. 사람·원어민 검토는 아닙니다.

## 게시 전 검증

실제 승인 기록이 아닌 임시 테스트 fixture 25개로 기존 게시 번역 5개와 함께 검증했습니다.

- `npm test` 15개 통과. 통합 테스트가 언어별 글 수를 실제 승인 파일 수와 대조하도록 수정해 다수 번역을 검증하고, 특정 글을 검색 순서와 무관하게 찾도록 했습니다.
- `npm run check`: 오류·경고 0개.
- 임시 공개 빌드: 사이트 HTML 815개, canonical 사이트맵 URL 413개. 후보 25개 URL이 추가됩니다.
- 해당 5개 글의 영어·한국어·번역 5개 언어, 총 35개 대응 페이지에서 자기 언어 canonical·HTML 언어·상호 `hreflang`·영어 `x-default`·색인 차단 여부를 확인했습니다.
- 새 번역 25개가 언어별 RSS·검색 인덱스·사이트맵에 포함됩니다. 내부 링크·이미지·앵커 검사도 통과했습니다.
- IndexNow 미리보기에서 기존 목록·관련 글 갱신을 포함한 변경 URL 50개를 확인했습니다. API로 실제 제출하지 않았습니다.

임시 파일 25개를 제거하고 다시 빌드한 결과 기존 HTML 790개, 사이트맵 URL 388개, 실제 게시 번역 5개로 복원됐습니다. 기존 승인·발행 기록의 바이트도 유지했습니다.
