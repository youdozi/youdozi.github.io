# 첫 다국어 공개 후보: 다중 리전 설계

다중 리전의 복제·쓰기·장애 전환 절충을 다룬 글 1편의 중국어 간체·일본어·독일어·프랑스어·러시아어 번역 5편을 최종 검토했습니다. 현재는 **게시 승인 대기**이며, 이 PR의 병합만으로 번역이 게시되지는 않습니다.

## 검토할 내용

- [영어 기준본과 번역 5편 전체](pilot-001.md)
- [정확한 배치 해시·공개 예정 URL](../releases/pilot-001.json)
- [독립 AI 검토·수정·SEO 검증 기록](../ai-reviews/2026-10-27-pilot-release-001.json)

영어 기준본은 승인된 짧은 보강 기사입니다. 이번 번역은 그 제목·주장 2개·빈 후속 확인·검토 초점을 모두 옮긴 것이며, InfoQ 원문 전체의 완역이 아닙니다. 원문 인용문과 링크는 공통 근거로 원문 그대로 표시합니다.

## 수정과 재확인

전역 `translate` 스킬로 독립 AI 세션에서 번역문을 먼저 읽고 영어 기준본과 대조했습니다. 중국어·러시아어에서 백분율이 비용 절감치에만 걸리도록 고쳤고, 일본어의 시험하지 않은 장애 전환 경로 표현을 다듬었습니다. 변경한 세 문자열은 같은 세션에서 재확인했습니다. 독일어·프랑스어에서는 해당 검토 범위의 수정 사항을 찾지 못했습니다. 영어 기준본과 원문 근거는 변경하지 않았습니다.

검토는 AI가 수행했습니다. 사람·원어민 검토나 원문의 성능·비용 추정치에 대한 독립 실험 검증을 의미하지 않습니다.

## 게시 전 검증 결과

`npm test` 15개와 `npm run check`를 통과했습니다. 기존 통합 테스트의 임시 게시 fixture로 다음을 확인했습니다.

- 해당 글의 7개 언어 페이지에 자기 언어 canonical과 올바른 HTML 언어가 표시됩니다.
- 실제 대응 글 7개끼리 자기 참조·상호 `hreflang`을 연결하고, `x-default`는 영어 글을 가리킵니다.
- 번역 5편에 언어별 Open Graph·구조화 데이터·검색 인덱스·RSS·사이트맵이 생성됩니다.
- 번역 발행일은 원문 뉴스 날짜와 분리되며, 빈 글 목록은 색인과 사이트맵에서 제외됩니다.
- 내부 링크·이미지·앵커 검사가 통과했습니다.

임시 fixture를 제거하고 `npm run build`를 다시 실행했습니다. 실제 게시 파일은 0개이며 기존 영어·한국어 사이트는 HTML 740개, canonical 사이트맵 URL 363개를 유지합니다. 공개되지 않은 번역의 검색엔진 색인·노출은 아직 검증할 수 없습니다.

## 게시 승인 후 절차

사용자가 이 후보 5편의 게시를 명시적으로 승인하면 실제 승인 근거와 해당 PR 번호를 기록해 `scripts/translations.mjs publish`로 게시 파일을 만듭니다. 실제 공개 시각을 새로 기록하고, PR 검증을 통과한 뒤 병합·배포합니다. 테스트 fixture의 승인 정보는 재사용하지 않습니다.

배포 후에는 Google URL Inspection과 Bing API로 새 URL의 수집·색인 정보를 확인하고 검색 노출·클릭을 추적합니다. 네이버는 서치어드바이저에서 확인합니다. API의 알림 접수나 SEO 태그 검증은 색인·순위를 보장하지 않습니다.
